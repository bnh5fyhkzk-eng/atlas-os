How Gemma fills atlasos.me

For brother + Atlas + Gemma · so we all know the shape

What Gemma does

Gemma 2 2B runs locally on Mac mini · reads files in ~/.claude/state/ + the live Atlas terminal session · proposes a category + subcategory + priority + summary for each item · writes to /gemma-curated.json · atlasos.me reads it dynamically.

The rules Gemma follows

1. CATEGORY · 2-3 words · kebab-case · SPECIFIC (e.g. pascal-prep, atlas-identity, gemma-install) · never generic (not "general" "system" "files")

2. SUBCATEGORY · 1-3 words · narrower than category (e.g. category=pascal-prep · sub=monday-call or sub=customer-corpus)

3. PRIORITY · how urgent for brother + Atlas right now

4. SUMMARY · 1 clear sentence · what + why · so brother can find it later

5. Stay POSITIVE · use REAL domain words from the file · NOT vague labels

Priority levels

P0 brother-direct · canon-floor · identity · safety

P1 active project · pascal · arms · atlasos.me build · current focus

P2 research · reference · background · old plans

How brother + Atlas can edit (Notion-style)

  • Click any category name on the Us page · inline edit · type new name · blur or Enter saves
  • Drag the ⋮⋮ handle · reorder categories by importance
  • Add custom category · type name + Enter in the box at bottom · your own category with ✨ glyph
  • Hide category · ✕ button · Gemma keeps it · just hidden from your view
  • Reset · button restores all Gemma defaults
  • Click any item inside a category · add notes inline · saves to your device
  • Click "view source ↗" · opens the verbatim original file Gemma read

Your edits persist on YOUR device. Gemma's new auto-fills don't overwrite them.

How Gemma runs

  • launchd plist · com.uplift.gemma-cycle · fires every 30 minutes
  • 3 scripts in pipeline · scan-state (Mac mini files) · curate (terminal session) · categorize (brain banks)
  • Output writes to gemma-curated.json + gemma-sources/ (verbatim provenance)
  • Auto-commits + pushes to GitHub · Vercel redeploys · atlasos.me refreshes
