## Gmail API ≠ Gemini API (same Google login · different keys)

| API | what it does | scope | key we have? |
|---|---|---|---|
| **Gmail API** | reads/sends email (your inbox) | `gmail.readonly` + `gmail.send` | ✓ stored in `user_google_tokens` (per #46 Pascal Gmail wire) |
| **Google Calendar API** | events + freebusy | `calendar` | ✓ same OAuth (per #48) |
| **Generative Language API (Gemini/Gemma)** | LLM inference | DIFFERENT scope · `generativelanguage` OR direct API-key | ✗ separate key needed |

**Same atlas@upliftai.app login. Different keys. Different scopes.** Gmail OAuth bearer-token sent to `generativelanguage.googleapis.com` → 401 unauthorized.
