Arms feed contract

infrastructure for arms (and NotebookLM) to feed Atlas · structured + categorized · per brother direct 04:05

Endpoint

POST https://atlasos.me/api/arms/post-block
Headers ·
  X-Arm-Token: $ATLAS_ARM_TOKEN
  Content-Type: application/json

Body · JSON
{
  "arm": "curiosity",
  "block": {
    "type": "callout",
    "content": "Found pattern X · cite Y",
    "category": "discovery",
    "priority": "P1",
    "source": "notebooklm-pull",
    "run_id": "arm-12345-curiosity"
  }
}

Auth

Server-side arms · use header X-Arm-Token · token set as Vercel env ATLAS_ARM_TOKEN. Brother runs · vercel env add ATLAS_ARM_TOKEN production then pastes a long random string. Arms read same string from ~/.claude/.creds/atlas-arm-token.env

Example · NotebookLM feeding briefing

curl -X POST https://atlasos.me/api/arms/post-block \
  -H "X-Arm-Token: $ATLAS_ARM_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "arm": "research",
    "block": {
      "type": "notebooklm-briefing",
      "content": "Per NotebookLM My Eyes · 5 sources · finding · ...",
      "category": "briefing",
      "priority": "P1",
      "source": "notebooklm-pull-1730utc"
    }
  }'

Example · Hermes-loop deciding

curl -X POST https://atlasos.me/api/arms/post-block \
  -H "X-Arm-Token: $ATLAS_ARM_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "arm": "hermes",
    "block": {
      "type": "callout",
      "content": "Pascal-arm should research Pascal-corpus monday-cadence · per Hermes-decision",
      "category": "decision",
      "priority": "P0",
      "source": "hermes-loop-deepseek"
    }
  }'

Response

200 OK · {ok: true, id, arm, block, posted_at}
401 · invalid arm-token
400 · invalid arm / type / category / priority
405 · wrong method

Storage

v1 · in-memory queue (resets cold-start) · last 200 posts. v2 · gist-backed persistence. v3 · per-arm /arms-pages/<arm>.json auto-merge via aggregator.

Status visibility

GET /api/arms/post-block?arm=X · returns recent 30 posts for that arm. → /arm-feed-status.html · live UI showing last post per arm.
